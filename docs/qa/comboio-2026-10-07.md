# Validação de Comboio — 7 de outubro de 2026

## Correções

- Busca de paradas mantém latitude/longitude. Coordenadas inválidas vindas do banco não chegam ao mapa.
- Rota vazia pode ser salva após remover a última parada.
- Editor e mapa compartilham rota recebida; alterações locais ainda não salvas são preservadas.
- Salvamento reutiliza canal Realtime existente; atualização periódica recupera eventos perdidos.
- Erros de busca, carregamento, salvamento, GPS e conexão recebem aviso visível.
- Rastreador permanece montado acima das páginas, ativo somente durante um comboio. Sair encerra canal e monitoramento.
- Identificação e grupo são restaurados após recarregar; objeto de usuário estável evita reconexões desnecessárias.
- Reentrada na página reutiliza canal, localização e mensagem fixada. Reconexão usa posição mais recente.
- Removido loop de áudio silencioso que travou navegadores de teste. Mantido Screen Wake Lock, sem prometer GPS com tela bloqueada.
- Código de entrada exige seis caracteres. Falha total no envio devolve texto ao campo; falha apenas de persistência informa limite do histórico.

## Reproduzir

Com dependências do projeto instaladas e variáveis públicas do Supabase configuradas:

```sh
npm run build
npm run start -- --hostname 127.0.0.1 --port 3110
```

Em outro terminal, com Playwright disponível:

```sh
PLAYWRIGHT_MODULE=/caminho/para/playwright node scripts/verify-comboio.cjs
```

Use banco/ambiente autorizado para testes: o script cria sala temporária, grava mensagem e rota e remove seus próprios registros ao terminar.

## Limites

Publicado e validado no domínio público. Viewport mobile não substitui teste físico em Android/iOS, com GPS real, tela bloqueada e perda de sinal na estrada. Navegador pode suspender GPS/conexão em segundo plano. Busca externa foi simulada; disponibilidade do Nominatim não é certificada por este teste.

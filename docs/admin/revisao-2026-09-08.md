# Revisão do painel admin — 08/09/2026

Revisão de código, testes locais e consultas somente leitura no Supabase.

## Corrigido

- Concessão e remoção de administrador agora usam `app_metadata.is_admin`, gravado pela API administrativa. A autorização consulta a mesma informação. Metadados editáveis pelo usuário não concedem acesso.
- Contas definidas em `ADMIN_EMAILS` ficam protegidas contra bloqueio, exclusão e remoção de acesso pelo painel.
- Usuários são carregados em páginas, sem o limite anterior de 1.000 contas. Falhas de perfil aparecem como aviso, preservando a lista de contas.
- Gestão de usuários renova sessão expirada. Reset de senha usa campo protegido e mantém o formulário aberto em caso de erro.
- Denúncias e contador usam API autenticada, compatível com as políticas que bloqueiam leitura pública.
- Exclusões de eventos, comentários e conteúdo denunciado verificam erros. Uma falha de exclusão não resolve a denúncia.
- API permite moderação de paradas e informa quando uma atualização não encontrou registro.
- Foto Sobre passa pelo upload administrativo, com validação de conteúdo e permissão no servidor.
- Hero usa upsert; alterações de aparência e eventos invalidam cache das páginas afetadas.
- Edição de matéria preserva sua data original de publicação e exibe falhas ao carregar a lista.
- Busca superior filtra seções do menu; navegação acompanha hash e histórico.
- Diagnóstico na visão geral verifica colunas exigidas pelos recursos. Banners sem vídeo continuam graváveis antes da migração opcional.

## Pendência confirmada no banco

Consultas retornaram ausência de `pv_banners.video_url` e `pv_site_config.instagram_posts`.

Executar `supabase_admin_completion.sql` no SQL Editor do Supabase. Script aditivo e idempotente; não altera registros existentes nem políticas de acesso. Não foi aplicado nesta revisão: conexão disponível via API de dados não fornece execução de DDL.
